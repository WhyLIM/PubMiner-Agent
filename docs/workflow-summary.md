# PubMiner Evidence Agent：工作流程总结

> 面向汇报的通俗版全流程说明。目标：让 AI 替研究者完成"文献调研的体力活"，产出每句话都能翻回原文的证据清单，由研究者做最终判断。

---

## 一、要解决的问题

生物医学研究者想确认一个问题（例如"某标志物对某癌症的预后有没有价值"），通常要：搜文献 → 逐篇读摘要 → 判断相关性 → 提取数据 → 汇总比对，动辄处理数百篇论文，耗时数周。

PubMiner Evidence Agent 把这条流水线自动化：研究者只需**用一句话说出研究目标**，系统自动完成检索、筛选、提取、比对，产出结构化的证据清单；**每一条结论都能点击查看论文原文依据**，最终采信与否由研究者审核决定。

---

## 二、全流程（七步 + 一道质检关卡）

以真实运行的一次任务为例（目标：结直肠癌预后标志物研究，检索上限 200 篇）：

### 第 1 步：文献检索（SEARCH）
- 根据研究目标自动生成专业检索式（同时生成中文解释，用户可预览修改）
- 调用 PubMed 官方接口执行检索，拿到候选论文编号
- 实测：命中 200 篇候选文献

### 第 2 步：获取原文（HYDRATE）
- 按编号把论文的"档案"取回来：标题、期刊、作者、摘要
- 其中约 90% 的论文还能从 PMC 开放获取库拿到**全文**，一并存档
- 每篇文献都记录了内容指纹，日后引用时可验证原文未被改动
- 实测：200 篇全部取回，其中 188 篇拿到了可分析的正文

### 第 3 步：三层筛选（SCREEN）
像漏斗一样逐层过滤，避免逐篇精读浪费算力：

| 层级 | 方法 | 效果 |
|---|---|---|
| 第一层 | 语义向量相似度初筛 | 与主题明显无关的直接跳过（约省 80% 算力） |
| 第二层 | AI 通读摘要判断相关性 | 给出"相关/不相关/存疑"判断和理由 |
| 第三层 | 存疑的再通读全文复核 | 尽量不漏掉边界情况 |

### 第 4 步：断言抽取（EXTRACT）
- 从每篇相关论文中提取结构化结论，例如：
  **"circulating tumour DNA（ctDNA）水平高 → 预后差"**
- 每条断言必须附带**原文出处**（哪一篇、哪一段、第几个字到第几个字）
- 系统会核验引文确实存在于原文，找不到的自动修复一轮，仍找不到就丢弃——杜绝 AI"编造引文"
- 实测：542 条结构化断言、865 条证据片段

### 第 5 步：实体归一化（NORMALIZE）
- 同一个东西的不同叫法合并：ctDNA / 循环肿瘤 DNA / tumor DNA 都指向同一条记录
- 标识符只采信权威数据库（NCBI Gene、PubTator），AI 自行发挥的编号一律不认
- 实在无法确定归属的，标记"待人工确认"，不冒充已解析

### 第 6 步：跨文献验证（VERIFY）
- 一篇论文说"有效"不算数，系统检查**多篇独立研究是否方向一致**
- 同一结论同时保留四种立场：支持 / 反对 / 无效应 / 不确定，冲突不会被抹平
- 辅助提取 p 值等统计指标，帮助判断证据强度

### 第 7 步：覆盖度质检 + 补充检索（COVERAGE → EXPAND，可选循环）
- 质检问题："找够支持这个结论的独立研究了吗？"
- 如果独立验证不足，系统自动通过**引文网络**（谁引用了它、它引用了谁）补充新文献，再走一遍第 2–6 步
- 最多扩展一轮，避免无限检索

### 第 8 步：证据聚合（AGGREGATE）
- 汇总所有证据，每条结论标注：几篇支持、几篇反对、几篇存疑、覆盖多少篇独立文献
- **≥3 篇独立研究同向 → 自动标记"独立验证"**，这是最有分量的结论

---

## 三、人机分工：AI 干活，人拍板

系统有一条红线：**AI 永远不会替研究者做最终决定**。

- 所有自动结论都停留在"候选"状态
- 界面提供审核队列：冲突的排最前，其次是缺独立验证的
- 研究者逐条查看证据原文后，点"批准 / 否决 / 待定"
- 只有批准后的结论，才允许导出到下游数据库（如 CBD 格式）

---

## 四、最终产出什么

| 产出 | 内容 | 用途 |
|---|---|---|
| 证据清单 | 542 条结论 × 865 条原文片段，每条可回溯 | 人工审核、写入研究数据库 |
| 知识图谱 | 标志物与疾病结局的关系网络，按实体类型着色 | 快速看清研究全景 |
| 综述报告初稿 | 自动生成的 Markdown 综述（含覆盖度评估） | 汇报底稿，须人工复核后采用 |
| 溯源问答 | 像查资料一样提问，系统用原文片段回答 | 写作时快速核对依据 |
| 多格式导出 | 综述 Markdown / 命题清单 CSV / 图谱 JSON / CBD 数据库格式 | 对接下游工作流 |

---

## 五、设计原则（汇报可强调的四点）

1. **可溯源**：每条结论都能一键翻回论文原文的具体段落，杜绝 AI 幻觉引用
2. **不隐藏分歧**：支持与反对的证据并列呈现，冲突结论自动置顶送人工
3. **AI 有边界**：检索、筛选、提取由 AI 完成，采信与否永远由研究者决定
4. **换领域只改配置**：目前面向"疾病预后标志物"研究；换到"药物靶点"等新研究方向，只需换一份配置文件，流程本身通用

---

## 六、一句话总结

> **研究者提出问题，AI 在数百篇论文中检索、筛选、提取并交叉验证，产出一份每句话都能翻回原文的证据清单；人负责审核拍板。**
